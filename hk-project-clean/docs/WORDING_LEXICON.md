## 凭据与个人数据（pii）

| 规则 | 正则 | 处理 |
|---|---|---|
| `email_not_example` | `[A-Za-z0-9._%+-]+@(?!(?:[A-Za-z0-9-]+\.)*example\.(?:test|com)|localhost)[A-Za-z0-9.-]+\.[A-Za-z]{2,}` | 邮箱一律用 example.test 域（可带子域） |
| `cn_mobile` | `(?<!\d)1[3-9]\d{9}(?!\d)` | 手机号用 138****0000 占位 |
| `cn_id` | `(?<!\d)\d{17}[\dXx](?!\d)` | 证件号用 0000…0000 占位 |
| `bearer_token` | `(?i)bearer\s+[A-Za-z0-9._~+/-]{16,}` | token 只从环境变量读，不落盘 |
| `oauth_token` | `(?i)(access_token|refresh_token)\s*[=:]\s*["']?[A-Za-z0-9._~/-]{16,}` | token 只从环境变量读，不落盘 |
| `api_key` | `(?i)\b(sk|pk|ak)-[A-Za-z0-9]{16,}` | 密钥用 <API_KEY> 占位 |
| `md5_like` | `(?i)\b(?:[a-f0-9]{32}|[a-f0-9]{40}|[a-f0-9]{64})\b` | 疑似哈希/签名，确认不是凭据再放行 |
