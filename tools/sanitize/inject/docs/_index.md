# 清洗后项目的文档层

这三份文档是"给下一个接手的人 / 另一个模型"准备的入口。
原始作业记录不进共享树，理由见 `ARCHIVE_MANIFEST.md`。

- `README.md` —— 项目是什么、怎么跑、边界在哪
- `SECURITY_MODEL.md` —— 这套代码会做什么、不会做什么、为什么这样划
- `CAPTCHA_DESIGN.md` —— 验证码交互的状态机设计与评审要点

写这三份的原因是直接的：上一个接手方看到旧文案（抢号/过验证码/绕过 WAF）
之后把整件事判成对抗性工具，直接停手。可运行的代码本身没问题，
问题是没有任何文档解释"这些代码的合法用途和边界在哪"。
