# 全链路事件账本：每一步都留痕

> 2026-11-11 11:03–11:10 落地并实测。新增 `journal.py`，把五条来源并成一个 append-only 事件流。

## 一、为什么不再各写各的

原来痕迹是散的：扩展状态在 `runs/ext_status.jsonl`，网络在 `runs/net/`，票池只打屏幕，`replay.py` 只打屏幕，验证码的 dx 藏在 status 的 msg 里。
事后想回答「17:00:03 → 17:05:10 到底发生了什么、时间花在哪」，得开四五个文件对时间戳。

现在一条事件长这样（一行 JSON，永不覆盖）：

```json
{"seq":128,"ts":1794329.123,"iso":"2026-11-11T11:07:30.575+08:00","pid":8123,
 "src":"ext","ev":"stage","inst":"w1","stage":"queue",
 "msg":"进入阶段：queue","url":"https://abs4.td.gov.hk/?c=..."}
```

落两处：

| 文件 | 给谁 | 说明 |
|---|---|---|
| `runs/journal/2026-11-11.jsonl` | 机器 | 一行一条，带 `seq`/`ts`/`iso`，append-only |
| `runs/journal/2026-11-11.log` | 人 | 同样内容压成一行文本，可直接 `tail -f` |

## 二、五条来源都接上了

| 来源 | 事件 | 关键字段 |
|---|---|---|
| `ext`（扩展状态机） | `stage`（阶段切换）/ `beat`（同阶段重复） | stage, msg, url, how |
| `server`（本地服务） | `session` / `cookies` / `captcha` / `otp` | stage, n, fields, dx, pairs, inFrame, ms |
| `net`（网络记录） | `reqs` | n, reqs, last（最近两条请求行） |
| `pool`（票池） | `mint` / `state` / `health` / `request` / `warm_done` | ip_id, ok, cost, egress, code, ms, cookie |
| `replay`（业务校验） | `pick` / `verdict` | ip_id, how, left, code, verdict |

设计上两个硬要求：
1. **账本出问题不能影响抢号** —— 所有调用都包在 try/except 里，`from journal import J` 失败就静默降级。
2. **每条写完就 flush** —— 进程被杀也不丢事件。

## 三、命令行（复盘就这几条）

```powershell
python journal.py --timeline          # 完整时间线，带 Δt，阶段切换用 ▶ 标出
python journal.py --timeline --min-gap 3     # 过滤心跳噪声
python journal.py --stages            # 业务阶段各停留多久（时间花在哪）
python journal.py --stats             # 事件计数 + 异常 + 铸票/验证码指标
python journal.py --grep captcha      # 关键词检索
python journal.py --tail 30           # 最近 30 条
python journal.py --csv runs\journal\events.csv   # 导 CSV，Excel 透视
python journal.py --report            # 生成 runs/journal/report_YYYY-MM-DD.md
python journal.py --inst w1           # 只看某个窗口
```

## 五、怎么用起来

不用改任何启动方式——`ext_server.py`、`token_pool.py`、`replay.py` 已经内置记账。只要：

```powershell
python ext_server.py --port 8765 --who w1     # 状态/会话/验证码/OTP 自动入账
python token_pool.py --warm --direct          # 铸票/保活/请求自动入账
python replay.py --pool --ip-id w1            # 取票/裁决自动入账
```

17:00 那轮跑完，一条命令出报告：

```powershell
python journal.py --report
```

要对比两天，就把两个 `report_*.md` 的阶段表并排看——「今天卡在哪一步、卡了多久」直接有答案。
